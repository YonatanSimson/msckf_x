# Third-party software

msckf_x is licensed under the GNU General Public License v3.0 (see `LICENSE`).
It is a clean-room implementation written from the papers listed in the plan's
appendix. The software below is used under its own license; all of it is
compatible with GPL-3.0.

## Linked into the library and tools (fetched by CMake or from the system)

| Component | License | Use |
| --- | --- | --- |
| Eigen 3.4 | MPL-2.0 | Linear algebra |
| OpenCV 4 | Apache-2.0 | Image I/O, pyramids, display |
| Sophus 1.22.10 | MIT | SE3 / SO3 types |
| yaml-cpp 0.8.0 | MIT | Calibration and configuration files |
| AprilTag 3.4.2 (AprilRobotics) | BSD-2-Clause | AprilGrid detection in the calibration cross-checks |
| basalt-headers (Usenko et al.) | BSD-3-Clause | Camera-model cross-check tests; the optical-flow front end in `src/vision/basalt_flow.cpp` is adapted from Basalt and keeps its notice |

| GTSAM (optional, test only) | BSD-2-Clause | Preintegration cross-check |

## Reference implementations read for mechanics (permissive licenses only)

Basalt (BSD-3), GTSAM (BSD), COLMAP (BSD-3), OKVIS2-X core (BSD-3), Kalibr
(BSD-3, except `ethz_apriltag2`), projectaria_tools (Apache-2.0: the
definition of the Fisheye624 camera model, `include/msckf/camera/fisheye624.h`,
and the reference fixture `tests/data/fisheye624_aria.csv` it generated).

## Run as separate programs, never linked or read

OpenVINS (GPL-3.0) and sqrtVINS (LGPL-3.0) are run as unmodified binaries by
`scripts/baselines/run_baseline.sh` for comparison only. Their source is kept
outside this repository and is not read.

## Python tools (`python/`, GPL-3.0 like the rest)

numpy (BSD-3), opencv-python (Apache-2.0), matplotlib (PSF-based), PyYAML
(MIT), rerun-sdk (MIT/Apache-2.0), projectaria-tools (Apache-2.0), rosbags
(Apache-2.0).

## Data

Datasets (EuRoC, TUM-VI, UZH-FPV, LaMAria, TartanAir, KITTI) are never stored
in the repository and keep their own terms. `tests/data/fisheye624_aria.csv`
holds projections of a published LaMAria calibration, generated by
`python/aria_fisheye_fixture.py`.
